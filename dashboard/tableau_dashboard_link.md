# Delhi AQI Data Analysis (2023) - Tableau Visualizations

This document contains direct access links to the interactive Tableau Public visualizations built for the 2023 Delhi Air Quality Index dataset. Each visualization has been published as an independent, modular sheet to ensure data stability and seamless interactive access.

---

## 📊 Live Tableau Public Links

* 📍 **[Symbol Map - Station Distribution](https://public.tableau.com/views/Book2_17894889785510/map?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**  
  *Geographic symbol map tracking daily AQI across 30 Delhi NCR stations in 2023. Features spatial distribution tracking, severity color-coding, proportional sizing by AQI, and single-day date filtering.*

* 🔮 **[6-Month AQI Forecast Model](https://public.tableau.com/views/Book3_17894907559570/Sheet1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**  
  *Predictive time-series model forecasting Delhi Air Quality Index (AQI) 6 months forward using 2023 monitoring station data and exponential smoothing trend modeling.*

* 🍂 **[Seasonal AQI Analysis](https://public.tableau.com/views/Book4_17894911840480/Sheet1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**  
  *Comparative analysis of average AQI shifts across seasons in Delhi NCR during 2023, highlighting severe winter pollution spikes compared to monsoon air recovery.*

* 📈 **[Monthly Trend Line & Station Metrics](https://public.tableau.com/views/Book5_17894915469430/Sheet1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**  
  *Time-series overview tracking monthly average AQI shifts, identifying peak pollution months, and evaluating station performance over time.*
